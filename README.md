# Portfolio personnel

Site vitrine personnel en HTML/CSS, intégrant Bootstrap 5 via CDN pour la mise en page et les composants (navbar, cards, carousel, formulaire).

## Aperçu

Une page unique organisée en plusieurs sections :

- **Accueil** — introduction
- **À propos** — présentation avec photo et texte (grille Bootstrap)
- **Compétences** — présentées sous forme de cards
- **Projets** — présentés dans un carousel / des cards
- **Contact** — formulaire (nom, email, message) avec classes de validation Bootstrap

## Technologies

- HTML5
- CSS3 (`style.css` personnel, surchargeant le thème Bootstrap par défaut)
- [Bootstrap 5](https://getbootstrap.com/) (via CDN)

## Structure du projet

```
.
├── index.html      # Page principale
├── style.css       # Styles personnels (surcharge Bootstrap)
└── README.md
```

## Lancer le projet en local

Aucune installation nécessaire (Bootstrap est chargé via CDN) :

1. Cloner le dépôt
   ```bash
   git clone <url-du-depot>
   ```
2. Ouvrir `index.html` dans un navigateur

## Responsive

Le rendu a été vérifié sur mobile, tablette et desktop via les outils de développement du navigateur.
